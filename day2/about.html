About QuickNotes

QuickNotes is a simple note-taking application designed to help you capture ideas and reminders quickly.

This page was built as part of the Web Foundations course using semantic HTML.

User Guide

  1. Type your note into the text box.
  2. Click the Add Note button.
  3. Review your notes in the Your notes section.
  4. Use the About page to learn more about QuickNotes.

Features

  • Quick note creation
  • Simple and clean interface
  • Easy navigation
  • Keyboard-friendly controls

Keyboard Shortcuts

Shortcut Action
Tab Move to the next control
Shift + Tab Move to the previous control
Enter Activate the selected control
Space Activate a button
